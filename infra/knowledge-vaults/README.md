# Folder vault Obsidian (development)

Backend dev membaca folder ini (`KNOWLEDGE_VAULTS_DIR` di `backend/.env`). Setiap subfolder = satu vault milik satu
user, dipilih di **Tools → Basis Pengetahuan**. Isi folder ini tidak ikut git (milik user).

Buka subfolder vault di Obsidian: *Open folder as vault* → pilih `infra/knowledge-vaults/<nama>`.
